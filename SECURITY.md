# Security policy

## Supported versions

Security fixes are provided for the latest published FabricNavigator release.
Older builds should be upgraded before a security issue is investigated.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
tokens, private keys, topology data, device configurations, or customer data in
an issue.

Use GitHub's private vulnerability reporting feature for this repository. Include
the affected FabricNavigator version, installation type, reproduction steps,
impact, and any relevant sanitized logs. You will receive an acknowledgement
through the GitHub security advisory conversation.

If private vulnerability reporting is not available, contact the repository
owner privately before sharing technical details.

## Scope

Reports about FabricNavigator's application code, update mechanism, installers,
appliance builders, credential handling, SSH terminal, SNMP discovery, and
WebView tunnel are in scope. Vulnerabilities in third-party projects should also
be reported to the relevant upstream maintainer.
